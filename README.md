# موقع ويدجت

موقع تعريفي لتطبيق «ويدجت» على iPhone: المزايا، لقطات الشاشة، طريقة إضافة الودجات، أنواعها، البيانات التي يحتاجها التطبيق، الأسعار، والأسئلة الشائعة، مع صفحات الخصوصية والشروط والتواصل.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `privacy.html` | سياسة الخصوصية |
| `terms.html` | شروط الاستخدام |
| `contact.html` | اتصل بنا |
| `style.css` | التنسيق |
| `assets/screens/` | لقطات شاشة حقيقية من التطبيق |
| `assets/icon.svg` | أيقونة الموقع |

موقع ثابت بدون أي أدوات بناء: HTML وCSS فقط، مع خطوط Google (Tajawal وAmiri) وأيقونات Tabler من jsDelivr.

## التشغيل محليًا

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر على GitHub Pages

1. ارفع المجلد إلى مستودع على GitHub.
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. سيظهر الموقع على `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

## قبل النشر

- راجع تقسيم الودجات المجانية و«بلس» وسعر الاشتراك في `index.html`.
